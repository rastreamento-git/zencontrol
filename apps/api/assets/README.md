# Identidade da ZEN SEGUROS

`zen-seguros.png` é o logo oficial fornecido pelo usuário, obtido de https://www.zensegurosbr.com/images/logo.png em 2026-10-20. A URL enviada usa o otimizador Next.js com `url=/images/logo.png`. O arquivo original foi preservado, incluindo transparência e proporção, e é servido localmente e incorporado em cada página da OS em PDF. A geração não depende de rede.

Os ícones das aplicações em `public/brand/zen-*.svg` são vetores próprios do ecossistema, com o monograma Z e variações de degradê azul; não substituem o logo oficial na OS.
