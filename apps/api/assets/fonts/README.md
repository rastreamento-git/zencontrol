# Fontes do documento

Liberation Sans Regular e Bold, sem modificações, provenientes de `pdfjs-dist@6.4.299/standard_fonts`. A licença distribuída com as fontes está em `LICENSE_LIBERATION`.

As fontes são incorporadas como subconjuntos no PDF para manter as métricas e a aparência consistentes em diferentes leitores e sistemas. Nenhuma fonte é baixada durante a emissão da OS.
